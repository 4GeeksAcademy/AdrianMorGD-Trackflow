# TrackFlow public website

Corporate website for TrackFlow, built as an independent Next.js App Router application under `uis/website`.

## Stack

- Next.js 16
- React 19
- TypeScript strict mode
- Tailwind CSS v4
- `next/image` for responsive remote imagery

## Routes

- `/` — corporate homepage
- `/get-a-quote` — quote request form with client-side phone validation

## Local development

```bash
npm install
npm run dev
```

The website uses Unsplash imagery as temporary visual content. Replace these URLs with approved production assets before launch.
